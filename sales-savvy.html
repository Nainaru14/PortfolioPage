Sales Savvy

Overview

Sales Savvy is a modular E-Commerce platform developed using Java, Spring Boot, MySQL, JWT and Razorpay.

Tech Stack

  • Java
  • Spring Boot
  • MySQL
  • JWT
  • REST APIs
  • Razorpay

Features

  • Authentication Module
  • Product Catalog
  • Cart Management
  • Payment Integration
  • Role Based Access Control
