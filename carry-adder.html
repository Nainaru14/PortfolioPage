XOR-Based 16-bit Carry Select Adder

Project Overview

This VLSI optimization project was designed to reduce area, propagation delay and power consumption compared to conventional Carry Select Adders. An XOR-based architecture was implemented and tested for performance improvements.

Technologies Used

  • VLSI Design
  • Digital Electronics
  • Timing Analysis
  • Circuit Simulation

Key Features

  • Reduced propagation delay
  • Power optimization
  • Area reduction
  • Performance comparison
  • Timing validation

Outcome

Enhanced knowledge in VLSI architecture, optimization techniques and circuit performance analysis.
